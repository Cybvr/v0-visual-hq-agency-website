# Client portal surface

Approved direction: the user's project-portal screenshot, adapted to VisualHQ's existing white surfaces, neutral borders, blue action colour and Inter interface typography. Mode: Operate.

The client arrives to understand what needs attention, open projects, review documents and complete assigned tasks. The company home supports several projects and company-level documents. Inside a project, the header establishes company/project context and status; horizontal navigation leads to Overview, Tasks, Files and Billing. The larger left column prioritizes outstanding actions and assigned tasks. The right column carries project billing and shared files. On mobile these stack in that order.

The agency company-management page retains its existing design. Its Client portal control manages explicit project/task sharing, client assignment and client-safe instructions. Source project descriptions, earnings and task bodies remain in agency-only collections. Shared views use allowlisted projections. Existing financial documents retain their IDs and public single-record link behavior.

The first release has no new payment processor, contract-signing integration, forms, unrestricted client uploads, or project-wide chat. Task feedback is available in its own client-safe thread, separate from internal comments. Every displayed control must have a real action. Empty states describe absent shared content without inventing progress, amounts or activity.

Verification: desktop and mobile screenshots use synthetic local-emulator data; two-client authorization and legacy routing are tested separately. Real client records are not modified by the demo tests.
